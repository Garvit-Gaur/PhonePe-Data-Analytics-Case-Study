# PhonePe Data Analytics Case Study

Exploratory data analysis of the supplied PhonePe state, district, transaction-category, device and demographic datasets using **Python, Pandas, NumPy, Matplotlib and Seaborn**.

## Business questions
- Which states have the highest and lowest transaction volumes?
- How does app-open activity change by quarter?
- Which transaction categories dominate the latest available quarter?
- Which device brands have the highest registered-user totals?
- Which districts have the highest population and density?
- How do registered-user counts compare with district population?
- Is population density associated with district transaction volume?
- Do state and district transaction totals reconcile by state-quarter?

## Methodology
1. Load and inspect all five CSV datasets.
2. Review missing values, types and duplicates.
3. Clean numeric fields containing commas, currency symbols or other formatting.
4. Analyze state-level transaction volume and app-open trends.
5. Compare transaction categories for the latest available year-quarter.
6. Aggregate registered users by device brand.
7. Analyze district population and density.
8. Join district transactions with demographic data.
9. Compare state-level and district-level transaction totals by state-quarter.

## Selected findings
- The state transaction dataset contains **36 distinct states** and 10,248 rows.
- The five highest states by total transactions are **Karnataka, Maharashtra, Telangana, Andhra Pradesh, Rajasthan**.
- The latest transaction-split period is **2021 Q2**; leading categories are **Peer-to-peer payments, Merchant payments, Recharge & bill payments**.
- Leading device brands by summed registered users are **Xiaomi, Samsung, Vivo**.
- Highest-population district in the supplied demographic file: **North 24 Parganas (West Bengal)**.
- Pearson correlation between district density and transaction count in the merged data: **0.308**. This is descriptive association, not causation.
- State-quarter transaction reconciliation mismatches: **0** across 504 matched records.

## Run locally

Activate the environment:

```bash
pip install -r requirements.txt

```
Open `PhonepeCaseStudy.ipynb` and run the cells from top to bottom.

## Limitations
- Analysis is limited to the five supplied CSVs.
- User-to-population ratio is an exploratory proxy, not an official adoption rate.
- Correlation does not establish causation.
- Confirm the source and licensing terms before publicly redistributing the supplied datasets. Only upload data you are permitted to share.
